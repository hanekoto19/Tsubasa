# バトルファクトリー図鑑データベース(HGSS / v1)

ポケモン ハートゴールド・ソウルシルバーの「バトルファクトリー」で使う、レンタルポケモンの名前・技・持ち物・タイプ検索用データベースです。個人利用限定(自宅PC上でサーバーを立て、同一Wi-Fi内のスマホ/タブレットからアクセスする想定)。ビルド不要で、`index.html` をブラウザで開くだけで動作します。

## ディレクトリ構成

```
pokemon-search-app/
├── index.html        検索UI(Lv50/100切り替え + ポケモン/技/持ち物/タイプの4タブ)
├── css/
│   └── styles.css    スタイル定義
├── js/
│   ├── data.js       データ本体(下記「データについて」を参照。無編集で複製したもの)
│   └── app.js         検索・表示ロジック(新規実装)
└── README.md
```

## データについて

- `js/data.js` は [nejiki49.github.io](https://github.com/nejiki49/nejiki49.github.io)(「ネジキダメージ｜バトルファクトリー ダメージ計算機」)の `js/data.js` を**そのまま複製したもの**です。**内容の書き換え・フィルタは一切行っていません。**
- 使用しているデータ:
  - `array["50"]` / `array["100"]`: Lv50 / Lv100(オープンレベル)それぞれのレンタル候補プール(全国図鑑番号と出現グループ)
  - `bfpokedata`(951件): レンタルポケモンの実際のセット(種族値・個体値・性格・技4つ・持ち物・特性・タイプ・重さ)。同じ種族でも複数セットが存在する
  - `weaponsdata`(467件): 技のタイプ・威力・命中・PP・分類・効果
  - `typeChart` / `tName`: タイプ相性表・タイプ名一覧
- `trainerdata` / `trainerList` は要件確認の結果、本アプリの用途では**使用していません**。
- クローンした `nejiki49.github.io` リポジトリ自体は直接編集せず、このディレクトリに `js/data.js` のみをコピーして利用しています。
- ポケモンの画像は [PokéAPI](https://pokeapi.co/) から毎回ライブ取得します(ローカル事前ダウンロード・キャッシュはしません)。`bfpokedata.pokeNo`(全国図鑑番号)がPokéAPIのIDと直接対応するため、`https://pokeapi.co/api/v2/pokemon/{pokeNo}` を取得し、**HGSS当時のドット絵**(`sprites.versions["generation-iv"]["heartgold-soulsilver"].front_default`、取得できない場合は公式アートワーク→デフォルトスプライトにフォールバック)を表示します。

## v1機能

- **Lv50 / Lv100(オープンレベル) 候補プール切り替え**: 画面上部の常時表示トグルで切り替え。ポケモン/技逆引き/持ち物逆引き/タイプ一覧のすべてのタブに反映されます。
- **ポケモン検索 + 複数選択で一覧比較**: 名前・タイプで絞り込み、カードのチェックボックスで複数選択すると比較表(タイプ・特性・持ち物・性格・技・種族値・重さ)が表示されます(レンタル選出画面で複数候補が出た時の比較用)。
- **技から探す(逆引き)**:
  - パターンA: 技名のみで検索 → その技を持つ可能性のある全セット
  - パターンB: 技名 + ポケモン名で検索 → そのポケモンの複数セットの中から該当技を持つセットに絞り込み
  - 「技図鑑」サブタブで技そのもの(威力・命中・PP・効果)も一覧検索できます
- **持ち物から探す(逆引き)**: 技と同様にパターンA(持ち物名のみ)/ B(持ち物名+ポケモン名)に対応
- **タイプ検索**: 選択したタイプの被弾倍率(弱点・耐性・無効)と、現在の候補プール内でそのタイプを持つポケモン一覧を表示(有利タイプを探す研究用)

## v1スコープ外(意図的に実装していない機能)

- 自分の3匹の一時登録・比較・Gemini APIによる自然言語診断(v2スコープ)
- インターネット上への公開・デプロイ、オフライン対応・PWA化
- `trainerdata` / `trainerList` を使った機能(トレーナー予測など)
- 複数の技を同時入力して段階的に絞り込むUI
- 画像のローカル事前ダウンロード・キャッシュ

## 動作確認方法

ローカルで簡易サーバを立てて確認できます。

```bash
cd pokemon-search-app
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```
