# バトルファクトリー図鑑データベース(HGSS)

ポケモン ハートゴールド・ソウルシルバーの「バトルファクトリー」で使う、レンタルポケモンの名前・技・持ち物・タイプ検索および交換診断用データベースです。個人利用限定(自宅PC上でサーバーを立て、同一Wi-Fi内のスマホ/タブレットからアクセスする想定)。

## ディレクトリ構成

```
pokemon-search-app/
├── index.html        検索UI(Lv50/100切り替え + ポケモン/技/持ち物/タイプ/交換診断)
├── css/
│   └── styles.css    スタイル定義
├── js/
│   ├── data.js       データ本体(下記「データについて」を参照。無編集で複製したもの)
│   └── app.js         検索・表示・比較ロジック(新規実装)
├── server.py         静的配信 + Gemini APIプロキシ(APIキーはサーバー側のみ)
└── README.md
```

## データについて

- `js/data.js` は [nejiki49.github.io](https://github.com/nejiki49/nejiki49.github.io)(「ネジキダメージ｜バトルファクトリー ダメージ計算機」)の `js/data.js` を**そのまま複製したもの**です。**内容の書き換え・フィルタは一切行っていません。**
- 使用しているデータ:
  - `array["50"]` / `array["100"]`: Lv50 / Lv100(オープンレベル)それぞれのレンタル候補プール
  - `bfpokedata`(951件): レンタルポケモンの実際のセット
  - `weaponsdata`(467件): 技データ
  - `typeChart` / `tName`: タイプ相性表・タイプ名一覧
  - `trainerdata[].kota`: 相手の個体値(周回数に応じた値)。トレーナー予測機能としては未使用
- 画像は [PokéAPI](https://pokeapi.co/) からHGSS当時のドット絵をライブ取得します。

## v1機能

- Lv50 / Lv100 候補プール切り替え
- ポケモン検索 + 複数選択で一覧比較
- 技/持ち物の逆引き(パターンA/B)
- タイプ検索(被弾倍率 + 候補一覧)

## v2機能

- **自分の3匹の一時登録**: 交換診断タブ、またはカードの「自分の3匹に登録」。ブラウザを閉じると消えます(永続化なし)
- **交換候補との自動比較**: 実数値(種族値・努力値・性格・個体値・レベルから算出)とタイプ相性(パーティの穴・全員弱点・耐性・無効、交換した場合の穴の変化)をロジック側で計算
- **Gemini APIによる推奨コメント**: 上記の数値比較結果だけを渡し、自然文の説明を生成。数値の再計算はAIに任せません。APIキーはクライアントに埋め込まず、`server.py` が環境変数 `GEMINI_API_KEY` を読んでプロキシします

## 動作確認方法

```bash
cd pokemon-search-app
# 図鑑・比較だけ使う場合でも server.py を推奨(AI診断も同じサーバー)
python3 server.py
# AI診断を使う場合
GEMINI_API_KEY=あなたのキー python3 server.py
# ブラウザで http://localhost:8080 を開く
```
